
# Divergence Mail

Dmail is for "D-mail"（Divergence Mail）concept from the anime game Steins;Gate, a message that can be sent to the past, altering worldlines.

My purpose is to build a temporary text transfer system like [hastebin](https://www.toptal.com/developers/hastebin). It's not to say that I want to build a clone of hastebin, but I want to build a much more simple and easy-to-use temporary text transfer system via python flask and react（my amateur level）.

Just as D-mails create divergent paths in spacetime, the dmail is the ephemeral bridges for information sharing. Building upon the simplicity of tools like haste-server, D-Mail serves as a minimalist, temporary clipboard sharing solution that helps users quickly transfer text across devices or to other people - a true divergence point for your data.
